# Simple E-Commerce Landing Page

A straightforward e-commerce landing page built using **HTML5**, **Bootstrap 5**, and basic **JavaScript**.


---

## 💡 What's Included

1. **Standard Bootstrap Navbar**:
   - Brand name (`MyStore`).
   - Links to sections (`Home`, `Products`, `About`).
   - Search input box.
   - Cart button that displays the total item count and opens a modal.

2. **Clean Hero Banner**:
   - Simple header with title, description, and "Shop Products" button.

3. **Category Filters**:
   - Standard button group (`All`, `Electronics`, `Clothing`, `Home`).

4. **Product Cards**:
   - Clean Bootstrap cards with product image, title, category, price, and an **Add to Cart** button.
   - Sized uniformly with standard Bootstrap grid classes (`col-12 col-sm-6 col-md-4 col-lg-3`).

5. **Live Search**:
   - Filters products in real-time as you type into the search bar.
   - Shows a simple Bootstrap alert if no items match.

6. **Shopping Cart Modal**:
   - Uses a standard Bootstrap Modal (`<div class="modal">`).
   - Displays a clean table of added items: Product Name, Quantity, Total Price, and a remove (`×`) button.
   - Shows the calculated total price.
   - Has "Clear Cart" and "Checkout" buttons.
